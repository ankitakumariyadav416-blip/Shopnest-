# ShopNest

A mobile-first demo shopping app built as plain HTML/CSS/JavaScript.

## Run
Open `index.html` in a browser. No installation is required.

## Included
- Home, Explore, Saved, Bag and Account
- Search and categories
- Product details
- Wishlist saved in localStorage
- Shopping bag and quantities
- Demo checkout and orders saved in localStorage
- Responsive mobile layout

## Important
This is a front-end demo. Payments, real authentication, real product images, inventory, shipping and production order management are not connected yet.

## Next production step
Connect Supabase (database + authentication + storage), then deploy the site on a hosting provider such as Vercel.
